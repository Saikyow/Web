# Лабораторная работа №1 — Веб-программирование


---

## Описание работы

В рамках лабораторной работы разработана HTML-страница, позволяющая определить попадание точки с координатами `(X, Y)` в заданную область на координатной плоскости.

Координатная плоскость и область отрисовываются средствами HTML Canvas.

Проверка введённых пользователем данных, определение попадания точки, работа с таблицей результатов и LocalStorage реализованы на JavaScript.

Стили страницы вынесены в отдельный CSS-файл.

---

## Параметры варианта

### X

Тип поля:

```text
Checkbox
```

Допустимые значения:

```text
-3, -2, -1, 0, 1, 2, 3, 4, 5
```

Несмотря на использование checkbox, одновременно можно выбрать только одно значение X.

Это контролируется с помощью JavaScript: при выборе нового значения остальные checkbox автоматически снимаются.

---

### Y

Тип поля:

```text
Text
```

Допустимый диапазон:

```text
-3 <= Y <= 5
```

JavaScript выполняет следующие проверки:

- поле не должно быть пустым;
- значение должно быть числом;
- значение должно находиться в диапазоне от `-3` до `5`.

При вводе некорректного значения отправка формы прекращается.

---

### R

Тип поля:

```text
Select
```

Допустимые значения:

```text
1
1.5
2
2.5
3
```

При изменении R координатная область на Canvas перерисовывается.

# Проверка попадания точки

Область состоит из трёх геометрических фигур:

1. прямоугольника;
2. четверти круга;
3. треугольника.

Точка считается попавшей в область, если она принадлежит хотя бы одной из этих фигур.

---

## Прямоугольник

Прямоугольник расположен в четвёртой четверти.

Условия попадания:

```text
0 <= x <= R
-R <= y <= 0
```

В JavaScript проверяются одновременно все четыре условия.

---

## Четверть круга

Четверть круга расположена в третьей четверти.

Радиус окружности:

```text
R / 2
```

Основное условие окружности:

```text
x² + y² <= (R / 2)²
```

Дополнительно проверяется расположение точки:

```text
x <= 0
y <= 0
```

---

## Треугольник

Треугольник расположен во второй четверти.

Его вершины:

```text
(-R / 2, 0)
(0, 0)
(0, R)
```

Уравнение наклонной стороны:

```text
y = 2x + R
```

Условия попадания:

```text
-R / 2 <= x <= 0
0 <= y <= 2x + R
```

---

## Итоговая проверка

Результаты проверки отдельных фигур объединяются логическим оператором `OR`.

Пример логики:

```javascript
const hit = inRectangle || inCircle || inTriangle;
```

Если `hit === true`, точка принадлежит области.

Если `hit === false`, точка находится вне области.

# Canvas

Для отрисовки координатной плоскости используется HTML-элемент:

```html
<canvas id="canvas"></canvas>
```

Работа с Canvas выполняется через двумерный контекст:

```javascript
const canvas = document.getElementById("canvas");
const ctx = canvas.getContext("2d");
```

На Canvas отображаются:

- координатные оси X и Y;
- стрелки осей;
- деления;
- область;
- проверенные точки.

---

## Масштаб

В программе используется масштаб:

```javascript
const unitScale = 50;
```

Это означает:

```text
1 единица координат = 50 пикселей
```

Размер области зависит от выбранного R:

```javascript
const scale = r * unitScale;
```

Например:

```text
R = 1   -> 50 px
R = 1.5 -> 75 px
R = 2   -> 100 px
R = 2.5 -> 125 px
R = 3   -> 150 px
```

---

## Перевод координат точки в координаты Canvas

Начало математической системы координат расположено в центре Canvas.

Координата X преобразуется следующим образом:

```javascript
pointX = xCenter + x * unitScale;
```

Координата Y:

```javascript
pointY = yCenter - y * unitScale;
```

Знак минус необходим потому, что в Canvas положительное направление оси Y направлено вниз, а в математической системе координат — вверх.

---

## Цвет точки

Если точка попала в область, она отображается зелёным цветом.

Если точка находится вне области — красным.

```text
зелёный -> попадание
красный -> промах
```

# Таблица результатов

После каждой проверки результат добавляется в таблицу.

Таблица содержит следующие столбцы:

| X | Y | R | Результат попадания | Дата и время |
|---|---|---|---|---|

Для добавления новой строки используются DOM-методы:

```javascript
document.createElement()
row.insertCell()
appendChild()
```

---

# Дата и время

Для каждого результата сохраняется момент выполнения проверки.

В LocalStorage сохраняется не готовая строка даты, а timestamp:

```javascript
timestamp: Date.now()
```

Для отображения используется:

```javascript
new Date(result.timestamp).toLocaleString("ru-RU")
```

Это обеспечивает:

- русскую локализацию;
- корректный формат даты и времени;
- пересчёт времени при изменении часового пояса клиентского устройства.

# LocalStorage

Результаты проверок должны сохраняться после перезагрузки страницы.

Для этого используется:

```javascript
localStorage
```

Результаты хранятся под ключом:

```text
results
```

---

## Структура одного результата

Каждая проверка представлена объектом:

```javascript
{
    x,
    y,
    r,
    hit,
    timestamp
}
```

Например:

```javascript
{
    x: 1,
    y: -0.5,
    r: 2,
    hit: true,
    timestamp: 1789325123456
}
```

---

## Сохранение

Поскольку LocalStorage умеет хранить только строки, массив результатов преобразуется в JSON:

```javascript
JSON.stringify(results)
```

После этого он сохраняется:

```javascript
localStorage.setItem("results", JSON.stringify(results));
```

---

## Загрузка

При загрузке страницы данные читаются:

```javascript
localStorage.getItem("results")
```

После этого JSON-строка преобразуется обратно в JavaScript-массив:

```javascript
JSON.parse(savedResults)
```

Сохранённые результаты заново добавляются в таблицу.

---

## Восстановление точек

После перезагрузки страницы сохранённые точки также повторно отображаются на Canvas.

При изменении R Canvas очищается и перерисовывается.

После этого отображаются сохранённые точки, соответствующие текущему значению R.

# CSS

Стили страницы находятся в отдельном файле:

```text
style.css
```

В лабораторной работе используются различные виды CSS-селекторов.

---

## Селектор идентификатора

Пример:

```css
#header {
    font-family: sans-serif;
}
```

---

## Селектор элемента

Пример:

```css
body {
    font-family: sans-serif;
}
```

---

## Селектор атрибута

Примеры:

```css
input[type="text"] {
}
```

```css
input[type="checkbox"] {
}
```

```css
button[type="submit"] {
}
```

```css
select[name="r"] {
}
```

---

## Псевдоэлементы

Используется псевдоэлемент:

```css
#header::before {
    content: "\2603";
}
```

Также используется оформление placeholder:

```css
input::placeholder {
    color: grey;
    opacity: 0.7;
}
```

---

## Наследование

Для `body` задаётся общий шрифт:

```css
body {
    font-family: sans-serif;
}
```

Дочерние элементы наследуют данное CSS-свойство.

---

## Каскадирование и специфичность

Например:

```css
span {
    font-size: 16px;
}

#header span {
    font-size: 18px;
}
```

Для элементов `span`, расположенных внутри `#header`, применяется второе правило, поскольку селектор `#header span` имеет более высокую специфичность.

---

## Блочная вёрстка

Основные части страницы размещены внутри блочных элементов.

Для визуального разделения используются панели:

```html
<div class="panel">
```

Пример оформления:

```css
.panel {
    border: 1px solid black;
    padding: 15px;
    margin: 10px 0;
    border-radius: 8px;
}
```
