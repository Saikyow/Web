# Лабораторная работа №2 — Веб-программирование (ИТМО)

Веб-приложение на базе **Jakarta EE (Servlets + JSP)** для проверки попадания точки с координатами $(X, Y)$ в заданную область на координатной плоскости при заданном радиусе $R$.

* **Выполнил:** Погорельченко Фёдор Фёдорович
* **Группа:** P3212
* **Вариант:** 12694

---

## Архитектура приложения (MVC)

Приложение реализовано в соответствии с шаблоном **Model-View-Controller**:

* **Controller (`ControllerServlet`)** — единая точка входа для пользовательских запросов (`/controller`). Определяет тип запроса:
    * при наличии параметров `x`, `y`, `r` делегирует обработку в `AreaCheckServlet` через `RequestDispatcher.forward(...)`;
    * при запросе на очистку (`?clear=true`) удаляет историю проверок из текущей сессии;
    * в остальных случаях возвращает главную страницу с формой и графиком (`form.jsp`).
* **Model (`AreaCheckServlet`, `PointValidator`, `AreaChecker`, `ResultRow`)**:
    * `AreaCheckServlet` (`/area-check`) защищён от прямого обращения по URL (принимает только `DispatcherType.FORWARD`), валидирует входные параметры, проверяет попадание в область, замеряет время выполнения скрипта и сохраняет результат (`ResultRow`) в `HttpSession`.
    * `PointValidator` проверяет корректность и допустимые диапазоны значений:
        * $X \in [-5; 3]$
        * $Y \in (-3; 5)$
        * $R \in (2; 5)$
    * `AreaChecker` вычисляет принадлежность точки заданной области варианта **12694**.
* **View (`form.jsp`, `result.jsp`, `script.js`, `style.css`)**:
    * `form.jsp` — главная страница: шапка с данными студента, интерактивный `<canvas>` с координатной плоскостью, форма ввода координат и таблица истории проверок, рендерящаяся на сервере из `HttpSession`.
    * `result.jsp` — страница с результатом последней проверки и ссылкой для возврата к главной форме (`/controller`).

---

## Функциональность

* **Два способа задания координат:**
    1. Через HTML-форму (выбор $X$ с помощью radio-кнопок, текстовый ввод $Y$ и $R$ с клиентской и серверной валидацией).
    2. По клику на интерактивный график (`<canvas>`) с автоматическим пересчётом экранных координат в математические относительно текущего значения $R$.
* **Сохранение истории в `HttpSession`:** все проверенные точки сохраняются в рамках пользовательской сессии, отображаются в таблице при возврате на главную страницу и автоматически отрисовываются на `<canvas>` с пересчётом масштаба при изменении радиуса $R$.
* **Очистка истории:** кнопка «Очистить таблицу» отправляет запрос на сервер для удаления списка результатов из сессии и очищает график.

## Стек технологий

* **Backend:** Java 17+, Jakarta Servlet API 6.1, Jakarta Server Pages (JSP)
* **Frontend:** HTML5 (`<canvas>`), CSS3, Vanilla JavaScript (ES6+)
* **Сборка и деплой:** Gradle / Maven, сервер приложений **WildFly**
